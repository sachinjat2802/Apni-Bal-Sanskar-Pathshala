🧹 Replace dangerouslySetInnerHTML with React components in about page

* 🎯 **What:** Replaced the use of `dangerouslySetInnerHTML` containing raw HTML with properly formatted React components (JSX) in `src/app/about/page.tsx`.
* 💡 **Why:** `dangerouslySetInnerHTML` can be a security risk (XSS vulnerabilities) and makes code harder to maintain and read. Converting to JSX allows React to properly parse, optimize, and safely render the content, resulting in better code health.
* ✅ **Verification:** Replaced class attributes with `className`, converted self-closing tags to proper JSX syntax, fixed missing closing tags and duplicate attributes, converted inline styles, fixed unclosed `Link` components, replaced multiline HTML comments with JSX comments, and removed redundant script tags that were already included in the layout. Verified the changes by running `npm run build` which succeeded successfully without any new errors.
* ✨ **Result:** Improved security and readability of the codebase without changing the visible output or functionality of the About page.
